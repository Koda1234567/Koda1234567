# Звонко — AI-менеджер продаж

Российский B2B голосовой AI-продукт. Исходный код браузерного пилота находится в `zvonko/worker.js`.

## Размещение
Cloudflare Workers для веб-интерфейса и демонстрации диалога. Не размещать персональные данные российских клиентов в Cloudflare. Для боевой эксплуатации нужна отдельная инфраструктура и локализация данных в РФ.

## Телефония
План A: SIP-транк клиента; план B: виртуальная АТС с поддержкой передачи медиапотока. Настройки в UI не означают подключённую телефонию. Настоящий SIP/RTP шлюз будет отдельным сервисом.

## Ограничения
Автоматические исходящие вызовы возможны только после проверки законодательства РФ, согласий абонентов и условий оператора. Прототип не инициирует телефонные вызовы.
