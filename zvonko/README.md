# Звонко — телефонный ИИ-менеджер продаж (Россия)

**Текущий приоритет — звонки, не чат.** Внешний сайт на Cloudflare: https://zvonko-ai.mishkafedotov09.workers.dev

## Компоненты

- **Cloudflare Worker / браузерный кабинет:** `worker.js`. Информация о способах подключить оператора и реальный статус теста. Cloudflare НЕ хранит номера/записи граждан РФ, и НЕ совершает SIP-звонков.
- **Голосовой SIP/RTP-шлюз:** `telephony/server.py`, `telephony/voice.py`, `telephony/config.py`. Сервер на территории РФ с Asterisk. Входящие звонки; ручной тестовый исходящий только на заранее разрешённый свой номер. 2-стороннее G.711 RTP, VAD, STT, локальная Qwen через Ollama и нейросинтез Vosk TTS.
- **Конфигурация и инструкции:** `telephony/README.md`, `telephony/asterisk`, `telephony/.env.example`.
- **Автотесты:** `telephony/tests`. Тестируют G.711, RTP и запрет неавторизованного/чужого исходящего номера.

## Что проверено

Опубликована новая телефонная главная в Cloudflare. Код шлюза и unit-тесты подготовлены; **живой звонок не проверен**, потому что SIP-оператор и сервер с Asterisk ещё не подключены. Действующий звонок не симулируем. Пароли SIP нельзя отправлять в публичный чат или сохранять в Cloudflare.

## Правила РФ

Статья 18 38-ФЗ запрещает автоматический набор номера для распространения рекламы без участия человека (даже при наличии согласия). Поэтому нельзя обещать массовый рекламный автодозвон. Приоритет — входящие звонки, обращения по инициативе клиента, законные ручные тесты; коммерческие сценарии проверяются отдельно. Для личных кабинетов и персональных данных — российская инфраструктура с учётом 152-ФЗ.
