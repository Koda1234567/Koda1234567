# Звонко 3.0 — локальный A/B-пилот

**Только локальное тестирование на собственном MicroSIP.** Это прототип; не запускать массовые звонки, не подключать публичный SIP-транк без отдельной оценки закона, согласия и лицензий.

## Что меняется

- **200**: старый `Stasis(zvonko,inbound)` остаётся без перенастройки.
- **201**: новый `Stasis(zvonko3,inbound)`, отдельное Python-приложение `server_v3.py` и контрольный API на `127.0.0.1:8767`.
- **LLM**: `qwen3.5:4b` (обновление с 1.5B, для RTX 4050 6GB), потоковые короткие фразы (до двух).
- **Голос**: только локальная Silero CIS Base `ru_ekaterina`; без автоматического возврата к Piper Denis.
- **Телефония**: возможность перебивать речь и продолжать диалог; RTP/SIP-звук остаётся локальным.
- **Продажи**: выяснение типа помещения, площади (включая произнесённые словами числа), пола и способа уборки; обоснованная работа с возражениями, вежливое завершение при отказе.
- **Никаких автоматических исходящих звонков**, нет CRM-записи, календарного бронирования и сбора личных данных.

## Установка в Ubuntu WSL2

Перед установкой проверьте, что старый 200 работает и XRay включён. Для модели Ollama должен быть настроен прокси в его systemd-сервисе — как при скачивании Qwen 1.5B.

```bash
cd ~/Koda1234567/zvonko/telephony
git pull
ZVONKO_DOWNLOAD_PROXY=http://127.0.0.1:10801 bash setup-v3-wsl.sh
bash start-v3-wsl.sh
```

Дождитесь `Connected to local Asterisk ARI`, затем позвоните **201** с того же MicroSIP. Терминал со звонковым движком не закрывать. Старый 200 можно запустить отдельно: `bash start-local-ai-wsl.sh`.

Скрипт установки **не перезапускает Asterisk**; он добавляет только 201 в `[zvonko-localtest]`, проверяет наличие 200 и создаёт резервную копию `/etc/asterisk/extensions.conf.before-zvonko-v3`.

## Сценарии для проверки

1. «Привет! Слышно меня?» — быстрый ответ без генерации LLM.
2. «У нас склад две тысячи пятьсот квадратов, бетон» — запоминание площади и покрытия.
3. «Уже наняли клининговую компанию» — выяснение проблемы, а не навязывание машины.
4. «Это дорого» — корректная реакция без выдуманной цены/скидки.
5. Перебить озвучку: «Подожди, у нас другое покрытие» — старый ответ должен прерваться.
6. «Сколько стоит?» — без неподтверждённых цифр; следующий вопрос не повторяет уже известную площадь.
7. «Свяжи с менеджером» — честное уведомление, что в тестовом стенде звонок не переводится.
8. «Мне неинтересно, до свидания» — прекратить разговор.
9. Несколько повторных реплик после перебивания — не зависать.
10. Проверить, что номер 200 после установки по-прежнему работает со старым процессом.

## Что логируется

Только технические времена распознавания, первой фразы и первого аудио, без полного текста чужого разговора; никаких файлов аудиозаписи. В процессе звонка заметка об объекте и площади хранится только в оперативной памяти.

## Ограничения

Первые аудио на реальном ПК, звуковая естественность и успешность продаж **пока не подтверждены**. Порог остановки речи может реагировать на акустическое эхо: для проверки лучше использовать наушники. Локальные Piper-голоса имеют лицензионные ограничения и историю обучения; перед коммерческим запуском необходимо проверить условия конкретной модели. Отсутствие CRM означает отсутствие реальных заявок и переводов на менеджера.

## База знаний VMD (обновлено 20 ноября 2026)

- `catalog_vmd.json` содержит **19 товарных моделей/семейств**: поломоечные, подметальные, роторную машину F13, машину EW-440 и 4 позиции аккумуляторов. Модели и часть характеристик проверены по официальному сайту VMD и предоставленному в переписке прайсу VMD от 27 мая 2026.
- `knowledge_vmd.py` на каждый разговор достаёт факты о подходящих машинах, умеет отвечать на «что продаёте», «расскажи про F60 B52» и сравнивать F60 B52 / BT52 и S1 / S2.
- В модель передаётся **только релевантная часть каталога**; полная модельная линейка передаётся как список названий. Настоящее обучение весов LLM не выполняется — это локальная база знаний с выборкой (RAG-lite), она лучше для обновления прайса.
- Розничные цены в прайсе от **27.05.2026** не считаются текущими; они **не размещены в публичном GitHub** и не произносятся клиентам до перепроверки. Для цены и наличия подключите подтверждённый актуальный прайс.
- По VMD F80 BT70 встречается противоречие комплектации литиевой АКБ в исходном прайсе: не обещать точную ёмкость до сверки.
- Для проверки без полноценного звонка: `cd ~/Koda1234567/zvonko/telephony && .venv/bin/python -m pytest -q tests/test_knowledge_vmd.py` (если pytest не установлен: `.venv/bin/python -m pip install pytest`).


## Исправление обрыва приветствия (20 ноября 2026)

По логам MicroSIP v3 распознавал короткие отрывки акустического эха как речь абонента прямо во время озвучки. Это запускало новый ход диалога и прерывало исходный TTS. Исправление переводит **только 201** во временный полудуплексный режим: во время ответа ИИ и 700 мс после него микрофонные RTP-кадры не поступают в распознавание. В частности, длинное приветствие заменено коротким.

**Важно:** пока идёт голос ИИ, его нельзя перебить — это намеренный компромисс до реализации настоящего акустического эхоподавления (AEC). После завершения реплики ИИ и небольшой паузы снова слушает. У тестового номера 200 прежний алгоритм не менялся.

После обновления кода остановите только v3 через Ctrl+C и выполните `git pull && bash start-v3-wsl.sh`. Тестируйте с наушниками и микрофоном, чтобы исключить акустическое эхо. Наличие кода и unit-тестов не означает подтверждённое успешное испытание в MicroSIP на компьютере пользователя.

## Бесплатный живее звучащий голос: Silero V5 CIS Base (MIT)

Для **201** теперь приоритетен локальный **Silero V5 CIS Base Nostress**, первый голос — `ru_ekaterina` (русский женский). Движок и модель бесплатны, модель опубликована под [MIT](https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS); **платный API не подключаем**. Скачивание модели происходит только при установке. Дальше текст речи и звук обрабатываются на компьютере. Качество и задержку на конкретном ПК нужно проверить, потому что телефонный кодек G.711 всё равно ограничен 8 кГц.

Остановите только запущенную версию 3.0 клавишами Ctrl+C и в WSL выполните:

```bash
cd ~/Koda1234567
git pull
cd zvonko/telephony
ZVONKO_DOWNLOAD_PROXY=http://127.0.0.1:10801 bash install-silero-v3-wsl.sh
bash start-v3-wsl.sh
```

Если XRay-прокси не нужен, можно запустить `bash install-silero-v3-wsl.sh` без переменной.

Если официальный сервер Silero отвечает `curl: (28) SSL connection timeout`, это **не установка нового голоса**: v3 не запустится, пока проверенная модель Екатерины не установлена. Денис больше не используется как запасной голос. Для обхода сетевого сбоя скачайте через браузер Windows **официальный** файл [v5_cis_base_nostress.jit](https://models.silero.ai/models/tts/ru/v5_cis_base_nostress.jit), затем укажите его путь из WSL:

```bash
ZVONKO_LOCAL_SILERO_FILE="/mnt/c/Users/ВАШ_ПОЛЬЗОВАТЕЛЬ/Downloads/v5_cis_base_nostress.jit" bash install-silero-v3-wsl.sh
```

Вместо `ВАШ_ПОЛЬЗОВАТЕЛЬ` подставьте имя каталога профиля Windows или перенесите загруженный файл в доступную папку WSL. Инсталлятор не заменяет существующие файлы Asterisk, выполняет реальный синтез и печатает `SILERO READY` только после успешной проверки. Если нового голоса нет, `bash start-v3-wsl.sh` выведет `ERROR: Ekaterina voice is NOT installed/verified` и завершится с ошибкой. Запуск **только с Екатериной** теперь используется по умолчанию; Денис не включается автоматически.

 После `SILERO READY` стартовый скрипт сам выберет бесплатный Silero. Позвоните **201** из MicroSIP. Исходный номер 200, общая настройка `ai.env` и конфигурация Asterisk не меняются.

Для текущего теста голос жёстко зафиксирован как `ru_ekaterina`, чтобы не возникало незаметных переключений. Смена на другие голоса будет отдельным явным изменением конфигурации.

Модель `v5_cis_base_nostress` не расставляет ударения в русских омографах автоматически, поэтому отдельные слова могут звучать непривычно. Коммерческая эксплуатация требует сохранения уведомления о лицензии MIT. Тесты кода не подтверждают звучание и скорость на вашем оборудовании.

## Смена голоса для 201 без риска для 200

Старый выбор голоса Piper больше не используется в `start-v3-wsl.sh`: версия 3.0 запускается исключительно с проверенной Silero `ru_ekaterina`.

```bash
cd ~/Koda1234567/zvonko/telephony
git pull
bash select-v3-voice-wsl.sh irina
bash start-v3-wsl.sh
```

Скрипт `select-v3-voice-wsl.sh` сохранён для истории и не влияет на запуск 201. Для проверки нового голоса используйте `install-silero-v3-wsl.sh`, затем `start-v3-wsl.sh`.

Выбор Piper через `ZVONKO_V3_PIPER_VOICE` для 201 больше не используется.

Платные голосовые сервисы текущим стартовым скриптом 201 не включаются. Их использование потребует отдельного явного решения и изменения конфигурации.
