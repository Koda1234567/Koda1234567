## Контракт между заданиями
- Радар: новые рыночные проблемы и источники.
- Разведка: 5–10 существующих малых компаний РФ и обоснованные гипотезы о нужде в ролике.
- Офферы: до 3 персонализированных черновиков по существующим лидам, плюс storyboard и критерии качества.
- Координатор: только реальные факты, status GO/ITERATE/STOP, критические пробелы, решение для владельца.

Выводы хранятся в ChatGPT Space JARVIS при доступности записи, иначе сообщаются пользователю. Первая проверка успешной передачи отчётов между задачами ожидается после 27.11.2026.

## Важно
- Это **автоматический анализ и подготовка**, а не полностью автономное агентство.
- Нет автоотправки писем, звонков, платежей, рекламы, закупки кредитов или публикаций.
- Для отдельного запуска **Claude Code** использовать Claude routines: https://code.claude.com/docs/en/routines; привязать репозиторий и роль `CLAUDE.md`.
- Для отдельного запуска **Codex** использовать Scheduled в Codex app: https://learn.chatgpt.com/docs/automations?surface=app; привязать репозиторий и роль `AGENTS.md`.
- Внешним агентам выдавать минимум прав, использовать изолированную ветку и PR вместо изменений main; без API-ключей в файлах.
- Инструкции не заменяют проверку технических разрешений внешних аккаунтов.
