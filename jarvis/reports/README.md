# JARVIS: Telegram-ready public reports

Эта директория используется только для коротких **обезличенных** сообщений, разрешённых для публикации в публичном репозитории.

При добавлении или обновлении одного из следующих файлов в `main` сработает GitHub Actions `JARVIS reports to Telegram`:

- `weekly-YYYY-MM-DD.md` — еженедельный сводный отчёт
- `approval-YYYY-MM-DD.md` — готовое к согласованию решение, без частной информации

Каждый файл должен содержать: дата, **только проверенные факты**, 0/фактическое число лидов, готовые пакеты, реальные ответы, подтверждённые оплаты, блокеры, ссылки на частные страницы Space (не копировать их приватное содержимое).

Никаких персональных контактов или секретов. Полные материалы остаются в Space.

Подключение и тестирование Telegram: [TELEGRAM_SETUP.md](../TELEGRAM_SETUP.md).
