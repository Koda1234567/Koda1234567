# JARVIS VMD Sales — автономный модуль

Создано 23.11.2026. Серверная часть для собственного бизнеса по продаже поломоечных машин VMD под заказ по России.

## Развёрнуто

- Платформа: **Cloudflare Workers**, отдельный скрипт `jarvis-vmd-sales`.
- Автоматический запуск: **каждые 5 минут** (UTC Cron `*/5 * * * *`).
- База данных: **D1 `jarvis_vmd_sales`**. Контакты покупателей, журнал и заявки хранятся только в приватной базе, не в этом публичном репозитории.
- Мониторинг: открытый документированный API GenTender (`https://gentender.ru/api/tenders/search`) по запросам «поломоечная» / «поломоечные». Каталог обновляется поставщиком ежедневно; поиск каждого запроса не чаще 1 раза в час. Официальные RSS ЕИС **отключены** после ошибок TLS `HTTP 526` и тайм-аутов при вызовах с Workers.
- HTTP: `GET /health` — безопасный статус, остальные `/admin/*` требуют секретный `ADMIN_TOKEN`.
- Код: [worker.js](./worker.js).

## Алгоритм

1. Каждые 5 минут выполняется цикл Worker; GenTender опрашивается не чаще 1 раза в час во избежание избыточной нагрузки. Ошибки источника регистрируются явно, а не выдаются за отсутствие спроса.
2. Сохраняет карточки с номером закупки, заказчиком, регионом, ценой и сроком подачи, если поле доступно. Отсекает закупки ремонта, запасных частей, аренды и реализации техники; повторы подавляются по номеру тендера. Первичная карточка не означает подтверждённого соответствия VMD.
3. Для первой отправки КП необходимы проверенный контакт отдела закупок, доказательство его публикации и разрешённый канал, соответствие модели потребности. Владелец предварительно разрешил персональную отправку таким адресатам 23.11.2026; отдельное согласование каждого письма не нужно, но проверка фактов обязательна. ТЗ невозможно подтвердить из одной карточки поиска.
4. Только при отдельно подключённых **Gmail OAuth credentials** отправляет персональное письмо с розничной ценой из утверждённого прайса. В Gmail берётся результат отправки; при сомнительном результате повторная автоматическая отправка заблокирована.
5. Если Gmail доступен, проверяет ответы на **уже отправленные** письма и фиксирует статус `REPLIED`. Автоматических обещаний по срокам, запасам и гарантиям нет.

## Что необходимо доделать перед продажами

- **Выполнено:** GenTender API успешно ответил с сервера 23.11.2026 в 08:35 UTC, 11 уникальных закупок добавлены в D1 (часть позднее отсеяна). Не обходить TLS ЕИС.
- **Требует действия владельца:** подключить Google OAuth с разрешениями Gmail API, передав в секреты Worker `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN` (никогда не помещать их в GitHub или чат). См. [GMAIL_SETUP.md](./GMAIL_SETUP.md).
- Проверить разрешённый канал исходящих коммерческих предложений. Если закупочная площадка принимает только заявки через личный кабинет, письмо не заменяет участие.
- Выверить модели и комплектации с текущим прайсом и техническим заданием. Цены в коде предварительные клиентские, с НДС; не окончательный счёт.
- Провести тестовый цикл: RSS → заявка → подтверждение контакта → письмо → Gmail Sent → ответ → CRM. До этого нельзя считать сервер полноценным автономным отделом продаж.

## Административные методы

- `GET /admin/status`: агрегат по CRM и ошибки фидов.
- `GET /admin/leads`: последние заявки (включая потенциально персональные данные; закрыто токеном).
- `POST /admin/run`: ручной запуск цикла.
- `POST /admin/qualify`: только реально проверенная заявка с `id`, `buyer_email`, `model_code`, `contact_proof_url`, `outreach_allowed:true`, `contact_verified:true` (доступ по админ-токену, без массового импорта неподтверждённых контактов).

## Эксплуатационные ограничения

- Работает **по расписанию каждые 5 минут**, но GenTender опрашивает не чаще 1 раза в час; это не непрерывно исполняющийся процесс.
- Free-лимиты Cloudflare ограничивают число запросов/время исполнения. Проверять события и ошибки в D1.
- Исходящие письма ограничены **не более 12 в сутки, до 2 за цикл**, и **не отправляются**, пока нет Gmail OAuth. Черновики, подготовленные другим модулем ChatGPT, не синхронизированы автоматически с D1.
- Не хранить здесь контакты или переписку клиентов, финансовые условия, стоимость закупки, приватные документы.
