# JARVIS · коммерческий конвейер (Handoff Protocol v1.0)
Дата: 2026-11-22. Владелец решений — человек. Агенты сами готовят исследования и документы; **контакты/платежи/публикации только после явного утверждения**.

## Источник правды
1. Обязательные правила: `AGENTS.md`, `REVENUE_PLAYBOOK.md`.
2. Проверенное состояние: `PIPELINE.md` и `leads.csv` в GitHub, а датированные доказательства/разборы — страницы пространства ChatGPT Space «JARVIS · внутренняя AI-команда».
3. Каждый плановый запуск обязан сначала прочитать существующий прогресс и не повторять компании/предложения. Если недоступен GitHub или Space — **явно сообщить о недоступности и сохранить результат в отчёт задачи**. Нельзя говорить, что запись сохранена, если инструмент записи не подтвердил успех.
4. Данные из прежних задач без точного доступа к тексту не считать проверенными. Нельзя выдавать плановую работу за фактически выполненную.

## Роли и передача
- **MON / RADAR (рынок):** до 3 свежих проблем и сигналов рынка. Факты: URL + дата. Не изобретать заявок/клиентов.
- **TUE/THU / PROSPECTOR:** найти до 10 реальных, релевантных малых компаний РФ. Каждая запись: id, название, сайт, сегмент, наблюдение с URL, почему может подойти предложение (гипотеза), официальный деловой контакт (если подтверждён), дата, статус DISCOVERED. Сохранить датированную страницу `JARVIS · лиды · YYYY-MM-DD`; при возможности зеркалировать в `leads.csv` без перезаписи старых записей.
- **WED/FRI / OFFER:** выбрать до 3 подтверждённых лидов из **последнего** отчёта PROSPECTOR; создать конкретный видеооффер, сценарий на 15 сек, раскадровку, примерную себестоимость и ТЗ; факты о товарах только из источников, пробелы отдельно. Сохранить `JARVIS · офферы · YYYY-MM-DD`. Не выдавать идеи ролика за сгенерированное видео.
- **WED / DEAL DESK, FRI / COORDINATOR:** сверить компанию, деловой контакт, релевантность, фактические утверждения, доступы/права, цену, ограничения, шаблон контакта, повторы. Создать до 3 *пакетов на утверждение*, отметить READY_FOR_REVIEW или NEEDS_RESEARCH, а не автоматически APPROVED.
- **Человек:** принимает решение по конкретному адресату/каналу/точному тексту/бюджету. Только прямое утверждение этих параметров позволяет агенту отправлять указанное сообщение. Общая фраза «согласен» на систему НЕ означает разрешение на отправку/генерацию с кредитами.

## Статусы CRM — без фальшивых переходов
`DISCOVERED` → `QUALIFIED` (доказательства) → `DRAFTED` (предложение) → `READY_FOR_REVIEW` (QA) → `APPROVED` (есть ссылка/цитата на конкретное разрешение владельца) → `CONTACTED` (есть подтверждение отправки) → `REPLIED` → `NEGOTIATING` → `PAID` (подтверждена оплата) / `LOST` / `ARCHIVED`.

**Запрет:** нельзя автоматически переводить статусы в APPROVED, CONTACTED, REPLIED, PAID по умолчанию, из оценок AI, из данных роликов YouTube или из предположения. Наличие публичного адреса не значит согласия на рассылку. При повторной проверке использовать стабильный id лида, не создавать дубликатов.

## Пакет на утверждение (один лид)
- **ID / бизнес / сайт / дата проверки:** ...
- **Почему именно этот бизнес:** 1–2 факта с первичными URL, отдельно гипотеза проблемы.
- **Подтверждённый деловой канал связи:** ... / нет.
- **Что продаём:** 1 × 15-секундное вертикальное AI-видео + субтитры + обложка + одна правка. Цена **9 900 ₽ — тестовая гипотеза**.
- **Что нужно уточнить у компании:** исходники товара, права на материалы, характеристики, условия, срок, договор.
- **Индивидуальный текст первого контакта:** 70–110 слов; без давления и обещания результатов.
- **Сценарий демо (3–5 сцен):** вымышленный товар/бренд до согласия компании.
- **Себестоимость и риски:** оценка, расходы на генерацию до разрешения = 0.
- **QA:** PASS / NEEDS_RESEARCH / FAIL, с конкретными основаниями.
- **Действие владельца:** `ОДОБРИТЬ КОНТАКТ [ID] + канал + финальный текст` или `ДОРАБОТАТЬ` или `ОТКЛОНИТЬ`.
- **Доказательства:** ссылки на источники, путь или ссылка на документ оффера.

## Стоп-сигналы
Никаких неконтролируемых массовых рассылок, автоматических оплат, API-секретов в Git, рекламы с реальными брендами без согласия, обхода требований площадок, фальшивых отзывов, использования чужого лица/голоса без согласия. Полномочия точечные, не подразумеваются из доступа к подключённым сервисам.

## Еженедельная метрика
Новые проверенные компании | прошли QUALIFIED | готовых пакетов READY_FOR_REVIEW | вручную утверждено | подтверждённо отправлено | ответов | согласованных пилотов | подтверждённых оплат и прямых расходов.

Если показатели нулевые — показать нули; не приукрашивать.
