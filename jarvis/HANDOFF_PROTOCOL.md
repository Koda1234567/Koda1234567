# JARVIS · handoff v2 — исследование → подтверждённая проблема → пилот
Дата смены фокуса: 22.11.2026. Публичный репозиторий: здесь только открытые факты и обезличенные тестовые данные.
## Источники
Читайте BUSINESS_VALIDATION.md, REVENUE_PLAYBOOK.md, PIPELINE.md, APPROVAL_QUEUE.md и свежие датированные страницы JARVIS Space. Не запускать прежние видео-задания.
## Роли
- **RADAR (пн):** сравнить 2–3 новые или изменившиеся операционные B2B-проблемы. Для каждой источник, конкретный процесс, существующее платное предложение, конкурентные заменители, почему проблема НЕ решается просто загрузкой файла в ChatGPT, риски внедрения. Предпочтительно текущая гипотеза SLA; переключать после обоснования.
- **PROSPECTOR (вт/чт):** 5–10 реальных организаций РФ из конкретной ниши (теперь выездной сервис). Для каждой: ID, официальный сайт, подтверждённый вид обслуживания с выездами, источник URL, публичный корпоративный канал, fit/гипотеза, дата. Проверить дубликаты. **Наличие услуги не подтверждает проблему.** Отдельные проверяемые записи в Opportunity Leads, Space.
- **OFFER (ср/пт):** не продавать «AI». Написать до 3 персональных предложений короткого диагностического разговора по проверенным организациям и подготовить 6 вопросов; описать демонстрационный *синтетический* пример и минимальную программу пилота. Условия оплаты/цены не обозначать без фактической сметы/входных данных.
- **COORDINATOR (пт):** проверка первичных источников, точности отрасли, отсутствия фальшивых утверждений о проблемах фирмы, каналов, готовности провести тест без личных данных, реальные ограничения и экономические допущения. При полной готовности передаёт готовый текст **на одобрение**, не отправляет.
## Статусы
`DISCOVERED → RESEARCHED → INTERVIEW_DRAFTED → READY_FOR_APPROVAL → APPROVED_FOR_SPECIFIC_CONTACT → CONTACTED → REPLIED → PROBLEM_CONFIRMED → PILOT_SCOPED → PILOT_APPROVED → PAID → DELIVERED`, либо REJECTED/ARCHIVED.
Ни один статус после READY_FOR_APPROVAL не назначать без подтверждения конкретного действия/ответа/договора/платежа. Не считать открытие страницы, демонстрацию или публичный прайс подтверждённой продажей.
## Проверка экономики
1. Точный scope в пределах ОДНОГО процесса.
2. Доступные на самом деле экспортируемые данные/правила SLA; интеграции запрещены на первом пилоте без отдельного решения.
3. Тестовый набор/ручной эталон, критерий правильности.
4. Временные затраты, лицензии, хостинг, поддержка, ошибки, обработка данных, комиссии, налоги.
5. Только после этого — сценарная цена и конкретное утверждение владельца. Согласие «давай искать новую нишу» не разрешает любые контакты и траты.
## Что показывать владельцу
До 3 карточек с названием и URL, подтверждённым фактом деятельности, **гипотезой**, точным черновиком сообщения, публичным деловым контактом, риском и выбором «Одобрить контакт [ID]» / «Доработать» / «Отклонить». Главное — 3 реальных разговора и один достоверный тест на данных, а не количество отчётов.
