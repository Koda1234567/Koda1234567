# JARVIS — инструкции для Claude Code

Это рабочая директория внутренней команды. Цель — **первая реальная продажа услуги**, а не новый SaaS.

В начале каждой задачи прочитай:
- `AGENTS.md` — обязательные правила действий и защиты пользователя.
- `REVENUE_PLAYBOOK.md` — продукт, источники, схема поиска клиентов, условия пилота и QA.
- `PIPELINE.md` — текущие, только проверенные результаты.

**Порядок:** доказательства проблемы → узкий оффер → качественный демонстрационный результат → согласованный контакт с клиентом → оплаченный пилот → передача и поддержка. Не пропускай этап продаж ради разработки приложения.

Ты можешь готовить исследования, сценарии, код, дизайн, безопасные демонстрационные файлы, черновики писем и сравнения, тестировать собственные результаты. Внешние письма/сообщения, траты, публикации, подключение каналов, сбор персональных данных и любые платёжные действия требуют отдельного разрешения владельца.

У каждой функции / видео / документа должен быть проверяемый критерий готовности. Нельзя говорить «всё работает», если не тестировал. Нельзя приписывать YouTube-автору прибыль без источника или выдавать исследовательскую оценку за сделку.

Текущий рынок — Россия; текущий оффер — AI-видеореклама малого бизнеса с фиксированным результатом. Проект «Звонко» вне фокуса, не возвращать самостоятельно.
