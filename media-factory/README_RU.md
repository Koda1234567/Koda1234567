# Media Factory · экспериментальная фабрика контента

Рабочее ядро без платных API: **6 последовательных программных агентов** для сборки одного 15-секундного пилота об истории Netflix.
Это архитектурные роли в Python, а не шесть автономных Claude-процессов. Подключение реальных LLM, видеомоделей, цифрового двойника и публикации — следующие независимые адаптеры.

## Что реально работает

1. **TopicScoutAgent** — забирает тему из карточки и передаёт факты с источниками.
2. **FactCheckAgent** — отвергает неподписанные факты, требует две ссылки. Не заменяет содержательную проверку фактов человеком.
3. **ScriptwriterAgent** — строит четырёхкадровый сценарий и хук.
4. **RenderAgent** — создаёт 9:16 PNG-карточки и собирает MP4 через FFmpeg (без искусственной речи).
5. **DistributionAgent** — пишет четыре набора метаданных и хэштегов; `publish: false`.
6. **AnalyticsAgent** — оценивает реальные просмотры/удержание/подписки из пользовательского CSV; не выдумывает метрики.

## Запуск

Нужны Python 3.10+, Pillow и FFmpeg:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python factory.py render --topic examples/netflix.json --output outputs/netflix
```

Для появления **статичного** портрета ведущего на карточках (это **не говорящий аватар**):

```bash
python factory.py render --portrait /путь/к/личному/портрету.png --output outputs/netflix
```

Результат: `outputs/netflix/preview.mp4`, `package.json`, `cards/*.png`, `drafts/{youtube,tiktok,vk,instagram}.json`.

Анализ после реальных публикаций:

```bash
python factory.py analyze --metrics examples/metrics_sample.csv
```

## Архитектура на перспективу

- Идеи/тренды: подключённый vidIQ и проверенные первичные источники -> очереди карточек.
- Сценарий и редактура: подключить Claude как **опциональный** инструмент разработки/генерации и оставить ссылочную проверку.
- Ведущий: закрытый локальный модуль с исходниками аватара пользователя; никаких публичных ссылок на исходное лицо/видео. При использовании генеративного видео — обозначить по правилам платформ.
- Видеомодели: отдельные адаптеры (fal, Higgsfield или свой пайплайн), только с разрешением на платные операции.
- Постинг: YouTube / TikTok / VK / Instagram через подтверждённые официальные интеграции, сначала ручное утверждение. Законодательные и региональные ограничения нужно проверять отдельно.
- Замеры: доступные метрики после публикации, тест гипотез по просмотрам, удержанию и конверсии в подписку.

## Безопасность

**Ничего не публикует, не отправляет файлы в облако, не клонирует голоса и не списывает деньги.**
Портреты и голосовые образцы хранить только вне публичных репозиториев. В локальном скачиваемом архиве есть приватный пример `assets/portrait_sample.png`; в публичном GitHub он отсутствует. `.gitignore` исключает `assets`, видео, фото и аудио.
Сценарии основаны на публичных ссылках и требуют ручного фактчекинга до публикации. Рекламные интеграции с лицом автора — только с его отдельным одобрением.

## Текущий честный статус

Есть рабочий прототип конвейера и первый **беззвучный технический MP4**, но **не** обученный цифровой двойник, не автоматизированный постинг и не автономный круглосуточный медиа-бизнес. Следующий этап — лицензированный генератор речи и постоянная модель/аватар с сохранёнными весами или разрешёнными экспортируемыми материалами.
